# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

`ui/` is the Angular 20 frontend of Kredius, a self-hosted personal finance app built on double-entry bookkeeping. It uses standalone components, signals and Tailwind CSS. The backend lives in `../be` (Spring Boot/Kotlin; see `../be/CLAUDE.md` for the domain model: accounts, journal entries, statement imports, loans).

## Commands

Run all of these from `ui/`:

```bash
npm start                  # ng serve on http://localhost:4200
npm run build              # production build → dist/ui/browser
npm run lint               # angular-eslint
npm test                   # Karma + Jasmine
npx ng test --include='src/app/app.spec.ts'   # run a single spec file
npm run generate           # regenerate src/app/api from the backend OpenAPI spec
```

The dev build calls the backend directly at `http://localhost:8080` (`environment.apiRootUrl`), so run `../be` with `./mvnw spring-boot:run` alongside `npm start`. The production build uses `apiRootUrl: ''`, so API calls go to the same origin. The k8s ingress routes `/api` to the backend and `/` to the nginx container serving the SPA.

Prettier settings are in `package.json`: `printWidth` 100, single quotes, and the angular parser for `*.html`.

## Generated API client

`src/app/api/` is generated by `ng-openapi-gen` from `../be/src/main/resources/api/openapi.yaml`, the same spec the backend generates its interfaces from. Never hand-edit it. After a spec change in `be/`, run `npm run generate` and commit the regenerated files.

Call the backend through the generated per-operation functions in `api/fn/<tag>/`, not through service classes. Inject `HttpClient` and `ApiConfiguration`, then call the function directly:

```ts
private readonly http = inject(HttpClient);
private readonly rootUrl = inject(ApiConfiguration).rootUrl;
getAccountsSummary(this.http, this.rootUrl).pipe(...)   // returns StrictHttpResponse; use res.body
```

The app provides `ApiConfiguration` with `environment.apiRootUrl` in `app.config.ts`.

Some older scaffolding is leftover and has no effect:
- `core/services/api.service.ts` and `environment.apiUrl` (`localhost:3000`) are not used.
- `core/guards/auth.guard.ts` and `core/interceptors/auth.interceptor.ts` are pass-through placeholders. The backend has no authentication yet.

## Structure

- The app has a single feature area, `features/accounts/`. `app.routes.ts` redirects everything to `/accounts`, which is lazy-loaded.
- `AccountsComponent` (`accounts.ts` + `accounts.html`) is the shell. It renders the sidebar list of accounts grouped by `AccountType`, with search, and a `<router-outlet>` for the right-hand panel.
- Each child route in `accounts.routes.ts` is a panel under `panels/`, such as detail, upload-statement, financing, income, dictionary or reports. The `reports` route uses `ReportsV2Component`; `reports.ts` is the older version.
- Panels are standalone components, mostly with inline `template:` strings. Some are large; `upload-statement.ts` is over 1,100 lines.
- Panels read the selected entity from query params (`route.queryParamMap`) and navigate back to `/accounts` to close.
- `AccountApiService` holds the shared account list as signals (`accounts`, `loading`). Panels that create accounts or loans call `load()` afterwards so the sidebar refreshes.
- Charts use `chart.js` directly, with no Angular wrapper.

## Conventions

- All user-facing text is in Spanish, and amounts are shown in RD$ or US$. Code and identifiers are in English.
- Use the new control flow (`@if`, `@for`) and `inject()`. Put component state in `signal`/`computed`.
- Tailwind theme (`tailwind.config.js`):
  - `brand-*` (violet) is the UI accent for navigation, toggles and CTAs. Never use it to convey financial meaning.
  - `income` (green) and `expense` (red) are reserved for financial meaning only.
  - `warning-*` (amber `bg`/`border`/`text`) marks a notice that needs the user's action, such as a missing US$ rate. It is not an error color.
- Shared component classes `.card`, `.card-row` and `.account-row` are defined in `src/styles.css` and use hairline 0.5px borders. `styles.css` also defines print styles: only `#schedule-card` and `#report-card` are visible when printing.
- Tailwind runs as v3 through `postcss.config.js` (`tailwindcss` + `autoprefixer`), even though `@tailwindcss/postcss` v4 is also installed.
