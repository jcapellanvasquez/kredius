# Kredius

> A personal, high-precision financial tracking engine designed for granular money management and full data ownership.

---

## Overview

**Kredius** is a self-hosted personal finance application built to replace generic budgeting platforms. It enables you to log every transaction down to the cent, structure custom multi-tiered spending categories, track balance histories across accounts, and maintain complete privacy on your own infrastructure.

---

## Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | Angular (Standalone Components, Signals, RxJS, Tailwind CSS) |
| **Backend** | Java / Spring Boot (Spring Security, Spring Data JPA, REST APIs) |
| **Database** | PostgreSQL |

---

## Key Features

* **Granular Ledger Engine**: Record detailed income, expenses, and internal transfers with custom tags, subcategories, and notes.
* **Multi-Account Hub**: Monitor cash, checking, savings, credit cards, and investments in one unified dashboard.
* **Custom Hierarchy**: Build flexible multi-tier category structures tailored to your exact spending habits.
* **Privacy & Control**: Keep 100% of your financial records hosted locally on your PostgreSQL instance.
* **Financial Analytics**: Real-time spending velocity charts, net worth tracking, and monthly cash flow summaries.
